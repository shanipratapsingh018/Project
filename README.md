## Download

- [Hosting-ready ZIP](downloads/carmechanic-indore-v1.5-hosting.zip) — on GitHub, click **Download raw**. Extract its contents into your hosting web root.
- [Complete source ZIP](downloads/carmechanic-indore-v1.5-source.zip) — on GitHub, click **Download raw**.
- Or choose **Code → Download ZIP** to download this whole branch.

## Run locally

Node.js 18+ is required. No npm install is needed.

```sh
cd carmechanic-indore
npm start
```

See [website README](carmechanic-indore/README.md) and [Hindi quick start](carmechanic-indore/docs/QUICKSTART-HINDI.md).
Bookings use WhatsApp. Set the real HTTPS domain and rebuild before enabling search indexing.

Validation: all 22 pages at mobile and desktop sizes, 276 price figures, unit/server/build tests,
and 22 focused browser reliability checks passed. The two owner-supplied Google review excerpts
retain The Car Junction attribution; 4.8 / 34 reviews is a labelled screenshot snapshot.
No external hosting deployment or live WhatsApp delivery was tested.
